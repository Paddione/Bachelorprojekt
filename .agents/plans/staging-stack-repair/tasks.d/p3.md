# P3 — db-restore-verify live-Verify (manueller Trigger)

Ziel: CronJob db-restore-verify live verifizieren (PGPASSWORD-Wiring ist im Manifest; nur live bestätigen).
budget_tokens: 32000 (min_tier 4b-local)

Live: ns workspace-staging, kubectl --context fleet. Kein Repo-Write.
Steps:
1. `kubectl -n workspace-staging create job p3-manual-restore-verify --from=cronjob/db-restore-verify`
2. `kubectl -n workspace-staging wait --for=condition=complete job/p3-manual-restore-verify --timeout=900`
3. `kubectl -n workspace-staging logs job/p3-manual-restore-verify` — DB-Verbindung/PGPASSWORD/Restore-Ergebnis.

Done when: job Complete, Logs ohne DB/PGPASSWORD-Fehler.
Stop when: job Failed → exakte Fehlerzeilen + Job-Status berichten; KEIN Manifest-Edit.
Rejected: Manifest-Edit (k3d/backup-restore-verify-cronjob.yaml exportiert bereits PGPASSWORD="$${SHARED_DB_PASSWORD}").
