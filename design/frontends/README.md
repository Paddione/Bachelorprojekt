# Frontend-Entwuerfe (Design-Canvas)

Exportierte Artboards aus dem Claude-Design-Canvas "SDLC Leitstand Frontend" (T901664).

- `Main.dc.html`, `Ticket.dc.html`: internes SDLC-Leitstand-Frontend (Token-Set `design/leitstand-ds`).
- `Massage.dc.html`: Marke massage (massege.korczewski.de).
- `Korczewski.dc.html`: Marke korczewski.
- `Mentolder.dc.html`: Marke mentolder.
- `canvas.json`: Canvas-Index (Positionen, Reihenfolge).

Stand: Entwurf. Farben und Schriften der Marken-Artboards sind Vorschlaege, nicht aus den Marken-Tokens abgeleitet. Die Dateien brauchen den Design-Canvas-Runtime (`support.js`) zum Rendern.
