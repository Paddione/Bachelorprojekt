## Task 2 — GREEN: fix the diff basis and add provenance (p1)

Edit `scripts/find-changed-tests.sh` around line 17 (the `CHANGED=` primary
source computation). Root cause: `git diff --name-only HEAD origin/main` is
a two-commit diff and never inspects the working tree — see
`openspec/changes/find-changed-tests-empty-T002713/design.md` for the full
measured root-cause trail.

Replace:

```bash
CHANGED="${FIND_CHANGED_TESTS_FILES:-$(git diff --name-only HEAD origin/main 2>/dev/null || git diff --name-only HEAD 2>/dev/null || true)}"
```

with a version that:

1. Uses `git diff --name-only origin/main` (single ref — per `git-diff(1)`
   this diffs the named commit against the working tree, covering both
   committed drift since `origin/main` AND uncommitted edits in one call).
2. Falls back to `git diff --name-only HEAD` only when `origin/main` itself
   fails to resolve (unchanged from today, still working-tree-based).
3. Tracks which of the three sources (`override`, `origin/main`, `HEAD`) was
   actually used, and always prints one line to stderr:
   `find-changed-tests: diff-source=<source> files=<n>` where `<n>` is the
   raw line count of `CHANGED` before the per-file classification loop
   (existing code from line 78 onward) runs — including the true-empty case
   (`files=0`).

Sketch (adapt variable names to match the surrounding style/comments
already in the file — keep the existing German inline comments intact,
extend rather than replace them):

```bash
if [ -n "${FIND_CHANGED_TESTS_FILES:-}" ]; then
  CHANGED="$FIND_CHANGED_TESTS_FILES"
  DIFF_SOURCE="override"
elif CHANGED="$(git diff --name-only origin/main 2>/dev/null)"; then
  DIFF_SOURCE="origin/main"
else
  CHANGED="$(git diff --name-only HEAD 2>/dev/null || true)"
  DIFF_SOURCE="HEAD"
fi
_changed_count=$(printf '%s\n' "$CHANGED" | grep -c '.' || true)
echo "find-changed-tests: diff-source=${DIFF_SOURCE} files=${_changed_count}" >&2
```

Notes:
- Keep the T002518 comment block above line 17 — extend it, don't delete
  it; it documents why the `FIND_CHANGED_TESTS_FILES` seam exists.
- Do not touch anything from line 78 (`while IFS= read -r file; do ...`)
  onward — the per-file classification logic, RUN_ALL triggers, and spec
  ancestor-dir probing are explicitly out of scope (see Non-Goals in
  `proposal.md`).
- `printf '%s\n' "$CHANGED" | grep -c '.'` (not plain `wc -l`) so an empty
  `CHANGED` counts as 0 rather than 1 (a `wc -l` on an empty string with a
  trailing newline from `printf` would otherwise misreport).
