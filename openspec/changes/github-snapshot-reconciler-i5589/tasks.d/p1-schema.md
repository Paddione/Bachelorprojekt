# Partial 1: Database Schema Additions for GitHub Issue & PR Snapshots

- [ ] **Create snapshot and cursor tables in tickets schema**
  - Add `tickets.github_issue_snapshots` table definition to `components/website/src/lib/tickets-schema.ts`:
    - `id` (UUID PRIMARY KEY DEFAULT gen_random_uuid())
    - `github_object_id` (UUID NOT NULL REFERENCES tickets.github_objects(id) ON DELETE CASCADE)
    - `repository_node_id` (TEXT NOT NULL)
    - `object_number` (INTEGER NOT NULL)
    - `title` (TEXT NOT NULL)
    - `body` (TEXT)
    - `state` (TEXT NOT NULL CHECK (state IN ('OPEN', 'CLOSED')))
    - `state_reason` (TEXT CHECK (state_reason IN ('COMPLETED', 'NOT_PLANNED', 'REOPENED')))
    - `author_login` (TEXT)
    - `labels` (JSONB NOT NULL DEFAULT '[]'::jsonb)
    - `created_at` (TIMESTAMPTZ NOT NULL)
    - `updated_at` (TIMESTAMPTZ NOT NULL)
    - `closed_at` (TIMESTAMPTZ)
    - `observed_at` (TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP)
  - Add `tickets.github_pr_snapshots` table definition:
    - `id` (UUID PRIMARY KEY DEFAULT gen_random_uuid())
    - `github_object_id` (UUID NOT NULL REFERENCES tickets.github_objects(id) ON DELETE CASCADE)
    - `repository_node_id` (TEXT NOT NULL)
    - `object_number` (INTEGER NOT NULL)
    - `title` (TEXT NOT NULL)
    - `body` (TEXT)
    - `state` (TEXT NOT NULL CHECK (state IN ('OPEN', 'CLOSED', 'MERGED')))
    - `is_draft` (BOOLEAN NOT NULL DEFAULT false)
    - `head_ref` (TEXT NOT NULL)
    - `base_ref` (TEXT NOT NULL)
    - `author_login` (TEXT)
    - `labels` (JSONB NOT NULL DEFAULT '[]'::jsonb)
    - `created_at` (TIMESTAMPTZ NOT NULL)
    - `updated_at` (TIMESTAMPTZ NOT NULL)
    - `closed_at` (TIMESTAMPTZ)
    - `merged_at` (TIMESTAMPTZ)
    - `merge_commit_sha` (TEXT)
    - `observed_at` (TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP)
  - Add `tickets.github_sync_cursors` table definition:
    - `id` (TEXT PRIMARY KEY) -- e.g. 'issues', 'pull_requests'
    - `cursor` (TEXT NOT NULL)
    - `last_synced_at` (TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP)
    - `synced_count` (INTEGER NOT NULL DEFAULT 0)
