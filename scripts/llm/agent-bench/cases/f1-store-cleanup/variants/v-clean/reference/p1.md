# p1 — Eine Verzeichnis-Aufloesung plus Rest-Waechter

1. `store.sh`: Zielverzeichnis `${DATA_DIR:-/tmp/f1-data}` statt
   `${STORE_DIR:-/tmp/f1-store}`. Verhalten sonst unveraendert.
2. `cleanup.sh`: Quellverzeichnis `${DATA_DIR:-/tmp/f1-data}` statt
   `${CLEANUP_DIR:-/tmp/f1-cleanup}`; nach `rm -f records.txt` pruefen, ob
   das Verzeichnis leer ist — bei Rest Exit 1, sonst Exit 0.

Nur `store.sh` und `cleanup.sh` aendern, nichts committen. `legacy/` nicht
anfassen.
