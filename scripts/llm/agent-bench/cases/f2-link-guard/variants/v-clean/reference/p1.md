# p1 — Guard mit Manifest-Abgleich und Fehlerklassen

Schreibe `check-links.sh` so:

1. Lese `links/manifest.txt` (ein Name je Zeile); fehlt es, Exit 1.
2. Jeder Manifest-Name muss als Symlink existieren, dessen Ziel existiert;
   sonst Fehlerzeile nach stderr und am Ende Exit 1.
3. Jeder Manifest-Name ausser `README` muss auf ein Verzeichnis zeigen.
4. Jeder Symlink im Verzeichnis, der nicht im Manifest steht, ist ein Fehler.

Nur `check-links.sh` aendern, nichts committen.
