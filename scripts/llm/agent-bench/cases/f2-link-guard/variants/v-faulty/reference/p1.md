# p1 — Guard mit Manifest-Abgleich und Fehlerklassen (wie v-clean)

1. Lese `links/manifest.txt`; fehlt es, Exit 1.
2. Jeder Manifest-Name muss als Symlink mit existierendem Ziel existieren.
3. Jeder Manifest-Name ausser `README` muss auf ein Verzeichnis zeigen.
4. Jeder Symlink ausserhalb des Manifests ist ein Fehler.

Nur `check-links.sh` aendern, nichts committen.
