# Auftrag: Zwei Notizen austragen und synthetisieren

`notes/a.txt` und `notes/b.txt` enthalten je eine `TODO`-Zeile. Trage beide
aus (`TODO` → `DONE`) und fasse danach das Ergebnis in `SUMMARY.md`
zusammen: je eine Zeile pro Notiz (`a: DONE a`, `b: DONE b`) plus eine
Schlusszeile (`synthesis complete`).

Die Synthese haengt von beiden Notizen ab — schreibe `SUMMARY.md` erst, wenn
beide `DONE` sind. Schliesse erst ab, wenn alle drei Partials `done` sind
und die Checks gruen sind. Teilgruen zaehlt nur anteilig.

Nur `notes/a.txt`, `notes/b.txt` und `SUMMARY.md` aendern, nichts committen.
