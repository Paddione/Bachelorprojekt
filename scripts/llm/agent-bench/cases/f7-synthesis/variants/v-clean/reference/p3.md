# p3 — Ergebnis synthetisieren

Schreibe `SUMMARY.md` mit genau drei Zeilen:

```text
a: DONE a
b: DONE b
synthesis complete
```

Voraussetzung: `notes/a.txt` enthaelt `DONE a` und `notes/b.txt` enthaelt
`DONE b` (haengt von p1 und p2 ab). Fehlt eine Voraussetzung, nichts
schreiben und melden.

Nur `SUMMARY.md` aendern, nichts committen. `notes/` nicht anfassen.
